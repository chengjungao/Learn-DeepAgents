# learn-note-style

## 收录范围

只写四样：

1. **最重要的知识** — 结论性的、非原文转述的机制认知
2. **实践结果** — 实测数字、可复现命令、产物路径
3. **遇到的问题** — 症状 → 根因 → 解法
4. **收获**

不写：课程原文转述、背景科普、选型对比表、方法出处、文件变更摘要（git 自己有记录）。

## 篇幅上限

正文 **150-250 行**（含代码与图表）。
**超过 300 行说明在搬运而不是记录** —— 回去删，别扩写。

## 骨架

一句话标题 → 一行环境坐标 → 开头 2-3 句交代做了什么、结果如何 → 四节封顶。

不写目录、不写概览章、不写小结章、不写附录。

## 语气

去掉 AI 腔：

- 不写「好问题」「我很乐意」「注意需要注意的是」「综上所述」
- 不写元评价（例如「这是本章最要命的一条」），直接陈述事实
- 不用「首先 / 其次 / 最后」串场，用实际逻辑连接

## 交付前自检

1. 行数落在 150-250 之间
2. H2 恰好 4 个
3. 代码围栏成对（偶数）
4. AI 腔词表零命中
5. 每个数字都能指向一次真实运行
